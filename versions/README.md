# Version archive

These directories hold the original local install and source archives. The ZIPs and original checksum records were copied without modification.

## v1.1.0

- `Dead_Space_2008_4GB_Mod_v1.1.0.zip`: original install package.
- `Dead_Space_2008_4GB_Mod_v1.1.0_Source.zip`: original source archive.
- `source-snapshot/`: browsable extraction of that exact source archive.
- `RELEASE_CHECKSUMS_v1.1.0.txt`: original checksum record, including the release description.
- `NEXUS_DESCRIPTION_v1.1.0.txt`: original release description cited by the checksum record.
- The original install ZIP contains `CHANGELOG.txt` and `CHECKSUMS.txt` inside it.

## v1.1.1

- `Dead_Space_2008_4GB_Mod_v1.1.1.zip`: original four-file install package.
- `SHA256SUMS.generated.txt`: checksum generated when assembling this GitHub backup. It is not a historical release file.
- No separate 1.1.1 source archive, source snapshot, or original checksum file was found locally. The bundled `dsound.dll` matches the 1.1.0 DLL byte for byte.

## v1.1.2

- `Dead_Space_2008_4GB_Mod_v1.1.2.zip`: original install package.
- `Dead_Space_2008_4GB_Mod_v1.1.2_Source.zip`: original source archive.
- Matching original `.zip.sha256` files for both archives.
- `NEXUS_CHANGELOG_4GB_v1.1.2.txt`: original release changelog.
- Browsable 1.1.2 source and build instructions are at the repository root. The root source is copied from the local checksum-verified source tree; it includes a few licensed MinHook support files not included in the release source ZIP.

The earlier 1.0.0 standalone patcher mentioned in project history had no matching install or source archive in this workspace at the time of this backup; it is not represented as a preserved release here.
